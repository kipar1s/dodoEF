# Система аутентификации и разграничения прав

## Описание реализации

Реализована полноценная система аутентификации и разграничения прав доступа для приложения Додо Пицца.

## Компоненты системы

### 1. Таблица Users в БД Access
- **Id** - уникальный идентификатор
- **Username** - логин пользователя
- **PasswordHash** - хэшированный пароль (SHA256)
- **Role** - роль пользователя
- **FullName** - полное имя
- **CreatedAt** - дата создания
- **IsActive** - активность учетной записи

### 2. Хэширование паролей
Используется алгоритм SHA256 для безопасного хранения паролей.

## Тестовые пользователи

При первом запуске автоматически создаются следующие пользователи:

| Логин   | Пароль  | Роль                |
|---------|---------|---------------------|
| admin   | admin   | Админ               |
| manager | manager | Управляющий         |
| deputy  | deputy  | ЗамУправляющего     |
| sales   | sales   | Менеджер            |
| kitchen | kitchen | Сотрудник Кухни     |
| courier | courier | Курьер              |
| intern  | intern  | Стажер              |

## Инструкция по тестированию

1. Запустите приложение
2. Откроется форма входа
3. Введите логин и пароль из таблицы выше
4. После успешного входа откроется главная форма
5. В зависимости от роли будут доступны только разрешенные формы
6. В заголовке окна отображается имя и роль текущего пользователя

## Безопасность

- Пароли хэшируются с использованием SHA256
- Неактивные пользователи не могут войти в систему
- При неверном логине/пароле выводится сообщение об ошибке
- Права доступа проверяются при каждой попытке открыть форму
